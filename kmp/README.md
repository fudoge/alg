# KMP - 문자열 패턴 검색

KMP는 길이 $n$인 텍스트에서 길이 $m$인 패턴을 $O(n + m)$ 시간에 검색하는 알고리즘이다.

핵심은 `lps` 배열이다. LPS(Longest Prefix Suffix)는 패턴의 각 위치까지의 부분 문자열에서 접두사이면서 접미사인 가장 긴 문자열의 길이다. 즉, `lps[i]`는 `pat[0...i]`에 대한 값이다.

## LPS 배열 만들기

`lps[0] = 0`, `len = 0`으로 초기화하고 `i = 1`부터 시작한다. `len`은 현재 일치하는 접두사와 접미사의 길이다.

- `pat[len] == pat[i]`이면 `len`을 1 증가시키고 `lps[i] = len`으로 설정한 뒤 `i`를 증가시킨다.
- 일치하지 않고 `len != 0`이면 `len = lps[len - 1]`로 바꾸고 같은 `i`를 다시 비교한다.
- 일치하지 않고 `len == 0`이면 `lps[i] = 0`으로 설정한 뒤 `i`를 증가시킨다.

패턴 `ABABAC`의 계산 과정은 다음과 같다.

| `i` | 처리 | `lps[i]` |
| --- | --- | --- |
| 0 | 초기값 | 0 |
| 1 | `pat[0] != pat[1]` | 0 |
| 2 | `pat[0] == pat[2]` | 1 |
| 3 | `pat[1] == pat[3]` | 2 |
| 4 | `pat[2] == pat[4]` | 3 |
| 5 | `pat[3] != pat[5]`이므로 `len = lps[2] = 1`로 줄여 다시 비교한다. `pat[1] != pat[5]`이므로 `len = lps[0] = 0`으로 줄인다. | 0 |

따라서 `lps = [0, 0, 1, 2, 3, 0]`이다.

## KMP 검색

텍스트 인덱스 `i`와 패턴 인덱스 `j`를 비교한다. 문자가 일치하면 둘 다 증가시킨다. 불일치할 때 `j > 0`이면 `j = lps[j - 1]`로 바꾸고, `j == 0`이면 `i`를 증가시킨다. 패턴 전체가 일치한 뒤에도 `j = lps[j - 1]`로 바꾸면 겹치는 일치를 계속 찾을 수 있다.

이미 일치한 `pat[0...j-1]`의 접미사는 같은 구간의 접두사와 일치하므로, 그 부분을 다시 비교할 필요가 없다.
